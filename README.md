# SalesPilot – E-Commerce Sales Prediction System

SalesPilot is a web-based E-Commerce Sales Prediction System designed to help users manage products, track sales, monitor revenue, and predict future sales through an interactive dashboard.

## 🚀 Features

- **Admin Login:** Login page with demo authentication.
- **Dashboard:** View total revenue, products, sales, and analytics.
- **Product Management:** Add, view, and delete products.
- **Sales Management:** Record and manage sales transactions.
- **Revenue Analytics:** Interactive charts using Chart.js.
- **Sales History:** View and search previous sales records.
- **Sales Prediction:** Estimate future sales based on historical sales data.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Local Storage:** Saves product and sales data in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.

## 📊 Sales Prediction

SalesPilot uses historical sales data to estimate future sales. The prediction is intended for demonstration and academic purposes and is not a guarantee of actual future sales.

## 💾 Data Storage

The current frontend version uses browser LocalStorage to save products and sales records. Data is stored in the browser and is not shared between different users or devices.

## 🎯 Project Objective

The main objective of SalesPilot is to provide a simple and interactive platform for managing e-commerce sales data, visualizing business performance, and understanding future sales trends.
